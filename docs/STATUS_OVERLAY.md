# 游戏状态窗（第一版）

入口：设置 → 游戏浮窗 → 打开状态窗。仅桌面客户端支持，应用每次启动默认隐藏。

## 操作

- 显示当前频道、连接状态、麦克风状态、屏幕共享、应用音频共享与当前说话人。
- 调整模式：拖动标题栏移动，右下角拖动缩放；点击麦克风切换开关，结果由主通话界面确认。
- 游戏模式：置顶、鼠标穿透，不接收鼠标操作。点击锁定按钮或在调整模式按 Escape 进入。
- `Ctrl+Alt+Shift+O`：显示 / 隐藏，快捷键显示时直接进入游戏模式。
- `Ctrl+Alt+O`：切换调整 / 游戏模式；隐藏时打开为调整模式。
- 可在设置修改快捷键；冲突或注册失败会显示错误，未取得有效快捷键时禁止进入穿透模式。
- 背景不透明度 10%–100%，默认 70%，文字和图标保持不透明。
- 默认尺寸 320 × 164，允许 260 × 140 至 560 × 300，尺寸为逻辑像素。
- 位置、大小、透明度和快捷键保存在应用配置目录的 `status-overlay.json`。关闭主窗口退出整个应用，关闭浮窗仅隐藏。
- 多显示器位置恢复会限制在可用工作区，设置中的“找回浮窗 / 重置位置”可恢复到主显示器。

## 游戏兼容范围

本版使用 Tauri 独立透明置顶窗口，优先面向窗口化与无边框全屏。独占全屏、管理员权限游戏、反作弊环境的显示效果需要逐个游戏实测，不能据普通置顶窗口承诺兼容。未实现游戏渲染注入。

KOOK 确有游戏内覆盖，但其官方帮助同样说明部分游戏不支持，并建议优先尝试无边框模式；这不说明其内部实现与本项目相同：[KOOK 游戏内覆盖不生效](https://help.kookapp.cn/65ea/0a4e)。

## 状态与架构

- `overlay.html` 是独立渲染入口，不导入主页面 runtime、LiveKit 连接或音频初始化。
- 主界面仍是通话状态与音频操作的唯一所有者。浮窗只接收序列化快照，操作通过 Rust 转发到主界面。
- 快照带递增序号和通话会话标识，旧快照不覆盖新状态。原生层在显示期间每 2 秒请求一次快照，变化另行合并推送。
- 超过 6 秒未更新时显示状态未知，禁止麦克风操作；重连及断开时清除说话人和媒体活动提示。
- 麦克风请求包含目标开关状态、会话和 5 秒期限；校验会话、拒绝并发，等待主界面执行后确认，不乐观显示成功。
- 网络提示仅复用诊断面板已有的问题，不另起一套网络采样或推断原因。
- 原生命令限制调用窗口；快照发布及麦克风结果只允许主窗口。浮窗权限仅包含事件订阅和窗口缩放。
- 外观使用独立组件与 `overlayTokens.css`，方便后续统一 UI 微调。未来聊天浮窗可复用窗口管理和状态传递方式，本版未加入聊天或游戏预设。

## 验证

新增前端协议测试覆盖状态构造、断线重连、快照顺序、会话失效、麦克风确认与失败、操作并发、心跳请求、订阅释放和浏览器降级。新增 Rust 测试覆盖偏好边界、快捷键校验、窗口调用权限、麦克风请求时效与多显示器坐标限制。

浏览器检查使用真实组件和模拟数据，覆盖默认/最小尺寸、调整/游戏模式、异常提示、状态过期和设置页窄窗口布局。浏览器检查不能验证桌面置顶、鼠标穿透、系统快捷键、焦点行为或真实通话同步；这些仍需桌面客户端及目标游戏实测。
