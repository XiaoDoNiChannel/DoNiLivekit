# 一键喊话（首版）

底部“一键喊话”打开音效面板。8 段初始素材来自本机“搞耍音频”目录，已复制到 `src-tauri/resources/soundboard/` 并编译进客户端，不依赖桌面路径。原始文件不做修改。部分素材虽命名为 MP3，实际是 MP4/AAC；WebView2 按内容解码，已全部验证。

## 使用

- 先点“试听”：仅本地播放，使用与发送相同的音量处理；跟随所选扬声器。
- 发送音量默认 60%，每段默认 100%，均可调整到 0–100%，设置自动保存。
- 默认 `Ctrl+Alt+1` 到 `Ctrl+Alt+8` 播放对应内置素材；点击快捷键按钮重新录入组合键或 F1–F24，Esc 取消。快捷键冲突会提示并保留原绑定。
- “停止播放”默认 `Ctrl+Alt+Backspace`。长按不会连播，快速触发有 300 ms 间隔。新音频替换旧音频。
- 频道播放需要已连接并开麦；静音、退出、切频道或重连时停止当前声音，不补播。关闭面板不停止播放。
- 收听设置支持全局接收音量、关闭所有喊话、屏蔽当前频道某个人。只有新客户端提供独立音效分类与屏蔽；旧客户端可能按麦克风处理该轨道。
- 可导入 MP3/WAV/OGG，单文件不超过 5 MB、30 秒、双声道；最多 64 段。点击名称可修改，删除操作有面板内确认。

## 音量处理

解码后计算各声道样本峰值与整体 RMS，仅衰减，不把安静素材自动放大：

`素材衰减 = min(1, 0.5 / peak, 0.1 / RMS)`

最终发送幅度 = 素材衰减 × 总音量 × 单段音量。这将归一化后样本峰值限制到约 -6 dBFS、整体 RMS 到约 -20 dBFS；默认 60% 后进一步降低。不是 LUFS 响度测量，也不代表设备上的实际声压。试听用于最终主观确认。

## 实现边界

- `commands/soundboard.rs`：本地素材库、内置素材初始化、受限 ID 读取、原子清单保存、增量全局快捷键注册。素材首次使用复制到应用数据目录的 `soundboard` 子目录，删除后不会重新补入。
- `features/soundboard.js`：解码缓存（最多 8 段）、独立发送与试听路由、播放取消、音轨生命周期。发布 `soundboard` / `unknown` 轨道，不经过麦克风降噪或 9001 程序采集。
- 连接后预先发布音轨；使用零值 ConstantSource 维持空闲时的音频时钟，避免短音效停止后在下次播放出现缓冲尾音。DTX 关闭。每次发布使用目标轨道的 clone，保证 LiveKit 断线清理不会终止原 Web Audio 输出。
- `shareSubscriptions.js`：独立音效分类，默认接收，不产生程序共享提醒；支持即时取消订阅与屏蔽晚到轨道。
- `remoteAudio.js`：独立接收增益，音效不改变麦克风/程序音量。
- `SoundboardModal.vue`、`soundboardStore.js`：界面和可序列化状态；快捷键与音量保存到现有 WebView 的 localStorage。

## 验证

`npm test --prefix ui` 与 `cargo test --manifest-path src-tauri/Cargo.toml --lib`。

端到端验证：启动 Vite，然后设置 `PLAYWRIGHT_MODULE` 为本机 Playwright 模块路径，运行 `node tests/soundboard_smoke.cjs`。测试使用两个独立无头 Edge 实例和本机临时 LiveKit（端口 17880–17882），不访问日常语音频道。验证素材解码、800/1360/480 宽度布局、音量交互、真实音频传输、停止、本地试听隔离、取消/恢复订阅以及完全断开后再次发布。报告与截图保存到 `tmp/soundboard-qa/`。

桌面版本使用 `npm run tauri -- build --no-bundle --target x86_64-pc-windows-msvc` 构建。游戏占用快捷键、独占全屏、不同耳机上的实际听感仍需在目标游戏中确认。
